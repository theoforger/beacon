## Findings

1. **[FIXED] Combo label capitalization.** Writing Style: sentence capitalization for "combobox labels". The row is "Country or region".
2. **[FIXED] Show tiles in search results had no cover.** A filling cover got no height inside the list's header; search tiles use a fixed 150px cover.
3. **[FIXED] "Everywhere" cut short at 360px** (before the scope toggle was dropped on 2026-11-11): the toggle wrapped under the field.
4. **[FIXED] The podcast page's header title cut to a few letters at 360px.** It shows only once the hero's title has scrolled away (decided by the user 2026-11-11).
5. **[FIXED] Log Out drawn plain and cramped.** Buttons: "Destructive action is a warning - it draws attention to the potentially damaging consequences of using a button." The row had `.destructive-action`, but building it with a class list had dropped the row's own `.button`; the class is now added, with a test that the row keeps every class a plain `AdwButtonRow` has.
6. **[PASS] Search.** Search: "The standard pattern for search in GNOME utilizes a search bar which slides down from beneath the header bar", toggled from the header, Ctrl+F and typing. Each page's field searches only that page (decided by the user 2026-11-11); its placeholder says which.
7. **[PASS] Search Online.** Placeholder Pages: "It can also be a good idea to include controls for relevant actions… This is one place where the suggested button style can be appropriate." Only Shows offers it.
8. **[PASS] Add page results.** Boxed Lists: rows that open another view "should have a `go-next-symbolic` arrow placed at the end". About 25 results, as GNOME Podcasts lists them. Searching only on Enter or Search departs from Search's "live wherever possible", for Apple's limit of about 20 calls a minute and at the user's request (2026-11-12).
9. **[PASS] One coloured button per view.** Buttons: "Each view should only ever include a single button using either the suggested or destructive styles": Add Feed, Subscribe, Search Online, Log In and Log Out each stand alone in their view.
