## Findings

1. **[PASS] Main menu icon, tooltip and label** (`app.rs`). Menus: "The button for primary menus should use the `open-menu-symbolic` icon." and "The menu button tooltip and accessibility label should refer to the menu as 'Main Menu'."
2. **[PASS] Main menu placement** (`app.rs`). Menus: with a sidebar, "the primary menu should be placed above the sidebar list."
3. **[PASS] Main menu items** (`app.rs`). Menus: About "should include the app's name, such as About Photos or About Calculator. Every primary menu should include this item." There is no Quit item, since "Primary menus shouldn't include menu items for _Close_ or _Quit_." Each item has its own access key ("Provide an access key for every menu item").
4. **[PASS] Header bar tooltips.** Header bars: "Primary window header bar controls should all have tooltips." The only header control has one.
5. **[PASS] Capitalization and punctuation.** Writing style: header capitalization for "headings in header bars … view titles … menu items and tooltips", and "Text generally shouldn't end with a period." "No Podcasts", "Main Menu", "Keyboard Shortcuts" and "About Beacon" comply, and the description has no period.
6. **[PASS] Minimum size.** Adaptive: "Apps that are appropriate for a phone form factor should scale down to 360×294px." The window sets 360×294 as its minimum and collapses at 760sp.
7. **[DEFERRED to M2] Placeholder guidance.** Placeholders: "It is often helpful to include a description which provides additional guidance, such as how to add items." and "It can also be a good idea to include controls for relevant actions, such as adding content". M0 has no way to add a podcast yet, so the description stays factual. M2 adds the guidance and an Add Podcast button.
