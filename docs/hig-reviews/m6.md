## Findings from the gate (2026-11-10)

1. **[FIXED] Field labels.** Writing Style: "Sentence capitalization should be used for labels that form sentences or that run on to other text, including … text entry boxes, field labels". Server address, Log in with, Last synced.
2. **[FIXED] Log Out was a button on the account row.** Boxed Lists: "Pill buttons are used when there is a single action which requires attention or delineation from the content above. In other cases, button rows are generally used." It is an `AdwButtonRow`.
3. **[FIXED] Last synced's control.** Boxed Lists: "When there is a control, clicking the list background should trigger the control." The row activates Sync Now.
4. **[FIXED] Toast wording.** Writing Style: "Text generally shouldn't end with a period" and "Pronouns like "you" or "my" should generally be avoided." "The sync server refused the login; log in again", "The login was not approved in time", "The keyring is not available".
5. **[PASS] One suggested button.** Buttons: "Each view should only ever include a single button using either the suggested or destructive styles." Log In, signed out only.
6. **[PASS] The waiting spinner.** Spinners: "A label can be shown next to a spinner, if it is helpful to clarify the task which a spinner relates to." The spinner is `Presentation`; the label is read.
7. **[PASS] Log in with.** Buttons: "Linked toggle buttons are primarily used to fit an option into a relatively short space, such as a list row". The group has the row's title as its accessible label.

## Found while taking the screenshots (2026-11-12)

8. **[FIXED] Login errors were hidden in narrow windows.** Preferences is a bottom sheet there, over the window's toasts, so "This is not a server address" was raised but never seen. Toasts: "Toasts should be positioned towards the bottom of their parent window". While Preferences is open, sync toasts go to its own toast overlay (`App::sync_toast`).
9. **[FIXED] An unreadable keyring signed the account out on screen.** The library still had the account, and its triggers kept recording, but the page showed the login form. Now the account stays signed in; launch says "The keyring is not available" once, and Sync Now says it again (`Sync::apply_loaded`, with tests).
10. **[NOTE] Preferences keeps the height it opened with.** The Sync page in Password mode has its Log In half under the dialog's bottom edge until scrolled, at 1440×900. Libadwaita sizes the dialog when it opens; the page scrolls as it should. Left as it is.
