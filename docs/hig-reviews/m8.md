## Findings

1. **[FIXED] A progress dialog.** Progress Bars: "In general, progress windows are not recommended". The import's progress moved into the content's thin refresh bar over Shows, where the new shows arrive, with a toast when it ends (decided by the user 2026-11-12).
2. **[FIXED] The progress text named no unit.** The bar's tooltip and accessible value said "12 of 44"; they say "12 of 44 podcasts" now.
3. **[PASS] Failures stay in a banner.** Banners: "used to communicate persistent states". The banner stays while some podcasts are not added; its Show opens the list, with Dismiss and Try Again, either of which takes the banner away.
4. **[PASS] Bad or empty files are toasts.** Dialogs: "For simple non-critical errors, toasts can be a good alternative". A file that cannot be read, is not OPML, or holds nothing new gets a toast.
5. **[PASS] The export warning shows only when it may matter.** Dialogs: "users will often habitually click through confirmation dialogs". It shows only when a feed address has a login, or a query parameter or path segment named like a key (narrowed 2026-11-12, as networks name public shows by UUID and tracking parameters look random).
6. **[PASS] One coloured button per view.** Buttons: "Each view should only ever include a single button using either the suggested or destructive styles": Try Again in the failures list, Export in the warning.
