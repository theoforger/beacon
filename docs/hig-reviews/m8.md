Result: **PASS so far** (2026-11-13, after Import and Export were redone as dialogs that list the podcasts to choose). The full screenshot set was taken on 2026-11-13 and the main window has not changed since, and every new dialog state that can be reached headless is checked here. Two rows stay in `pending-screenshots.md` for a person at a real session: dragging a file from Files onto the Import dialog's drop box, and the portal file choosers in the Flatpak. The Orca and keyboard row waits for M9, as decided on 2026-11-08. M8 closes once those two rows are checked and the user has reviewed the running app.

Pages checked (fetched 2026-11-12 and 2026-11-13): Dialogs, Check Boxes, Boxed Lists, Buttons, Pointer & Touch, Placeholder Pages, Spinners, Progress Bars, Selection Mode, Toasts and Writing Style at https://developer.gnome.org/hig/….

## Findings

1. **[FIXED] Toasts cut short at 360px.** "The file is damaged, or is not a list of subscriptions" was cut to "…not a list of…" on the Import dialog, as a toast does not wrap. The messages are now "The file is damaged", "Not a list of subscriptions" and "No new podcasts in the file".
2. **[FIXED] The loading bar did not show.** It was given its style class by replacing the bar's classes, which dropped `horizontal`; it is added now, as the content's refresh bar does.
3. **[FIXED] Alt+C did two things.** "_Cancel" and "_Choose File…" shared it; Choose File… is Alt+F.
4. **[PASS] Cancel first, the action last and insensitive until something is chosen.** Dialogs: action dialogs have "two primary buttons", "Always ensure that the cancel button appears first, before the affirmative button", and "the affirmative dialog button should be insensitive until the required options have been selected". Import and Export… are unavailable on the drop page and while nothing is checked; Escape cancels.
5. **[PASS] Button labels.** Dialogs: "Label the affirmative button with a specific imperative verb". Writing Style: "Use an ellipsis (…) at the end of a label if further input or confirmation is required": Choose File… and Export… open a file chooser; Import acts at once.
6. **[PASS] A row toggles its check box.** Boxed Lists: "When there is a control, clicking the list background should trigger the control", and rows "should generally just have one" control: the check box.
7. **[PASS] One progress bar, not a spinner per row.** Spinners: "Avoid showing numerous spinners simultaneously"; "If the task is likely to take more than 30 seconds, a progress bar might be a better choice". Rows show the placeholder cover until their feed loads.
8. **[PASS] The import itself is not a progress window.** Progress Bars: "In general, progress windows are not recommended". The dialog closes on Import; the content's thin bar over Shows and a toast follow it.
9. **[PASS] One coloured button per view.** Buttons: "Each view should only ever include a single button using either the suggested or destructive styles": Import or Export… only; Choose File… is a plain pill in open space ("Pill can be used when a text button is situated in open space, and is a primary action for the view").
10. **[NOTE] A boxed list for up to a few hundred rows.** Boxed Lists: "appropriate for relatively small static lists". A subscription file is the largest it holds, and its rows change only as feeds load; recorded in `docs/decisions.md`.
11. **[NOTE] No HIG page covers drop zones.** The drop box borrows the Add Podcast tile's dashed border and turns accent while a file is over it; Pointer & Touch's only drag rule, "Pressing Esc while a pointer operation is in progress should cancel it", is GTK's own behaviour.
